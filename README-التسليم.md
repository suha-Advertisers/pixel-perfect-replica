# حزمة استكمال منصة دليل المعلنين

هذه الحزمة مبنية فوق مشروع `pixel-perfect-replica` الأصلي وتحافظ على بنية React/TanStack Start والتصميم الحالي. لا تستبدل مشروع Supabase ولا تحذف جداولك الحالية.

## محتويات التعديل

- إدارة المعلنين: CRUD، بحث، تصفية، CSV export، حذف مؤقت واستعادة، حقول أسعار وروابط اجتماعية.
- استيراد CSV مع معاينة أساسية وتجاوز التكرارات.
- قوائم شخصية مرتبطة بالمعلنين، إجماليات الأسعار، وإرسال للمراجعة.
- الحملات: CRUD وحالات وتواريخ وميزانية وربط اختياري بالفرع.
- مراجعة طلبات القوائم.
- المستخدمون: دعوات البريد عبر Edge Function، تغيير الدور والتفعيل، وإدارة مصفوفة صلاحيات الأدوار.
- سجل العمليات، سلة المحذوفات، التقارير، الفروع، المناطق والمدن.
- Migration واحدة توسع قاعدة البيانات الحالية، تضيف RLS ونطاق الفروع وسجل تدقيق تلقائي للمعلنين، وتمنع منح صلاحيات الإدارة العليا إلا لمدير النظام.

## طريقة التطبيق — مرة واحدة

1. خذ نسخة احتياطية من قاعدة Supabase الحالية.
2. فك ضغط الحزمة واستبدل ملفات المشروع الحالية بمحتويات مجلد المشروع في الحزمة. لا تستبدل ملف `.env` الموجود عندك.
3. تأكد أن `VITE_SUPABASE_URL` و`VITE_SUPABASE_PUBLISHABLE_KEY` مضبوطان في Render. لا تضع `service_role` أو أي Secret في متغير يبدأ بـ `VITE_`.
4. افتح Supabase SQL Editor في المشروع الحالي `bzwimjyrfrrxddmgpois`، والصق محتوى `supabase/migrations/20261116010000_complete_platform.sql` ثم نفذه مرة واحدة.
5. من جهازك الذي يحتوي Supabase CLI، اربط المشروع أولاً بالأمر `supabase link --project-ref bzwimjyrfrrxddmgpois` ثم انشر وظيفة الدعوات بالأمر `supabase functions deploy invite-user`، ثم تأكد من توفر أسرار الوظيفة `SUPABASE_URL` و`SUPABASE_ANON_KEY` و`SUPABASE_SERVICE_ROLE_KEY` من Supabase Secrets فقط (لا تضع مفتاح الخدمة في ملفات المشروع أو Render للواجهة).
6. ارفع كامل التعديلات إلى المستودع الحالي `suha-Advertisers/pixel-perfect-replica` على فرع `main`، مع عدم رفع `.env` أو أي أسرار.
7. انتظر انتهاء نشر Render ثم ابدأ الفحص من الرابط المنشور.

## تنبيهات مهمة

- ملف `.env` الأصلي مستبعد من هذه الحزمة عمداً. لا تنسخه إلى GitHub.
- دعوات Auth تنفذ عبر Edge Function مستقلة؛ لن تعمل حتى تنشرها وتضبط الأسرار في Supabase Secrets كما في الخطوات أعلاه.
- استيراد CSV يدعم صيغة CSV بسيطة مفصولة بفاصلة أو فاصلة منقوطة أو Tab؛ لا يدعم XLSX/XLS مباشرة.
- إدارة القوائم والحملات وربط المعلنين بالحملات وحفظ السعر المتفق عليه موجودة؛ لا تزال نجمة التعاون التاريخي الخاصة بكل فرع والتقارير التاريخية الموسعة بحاجة استكمال مستقل.
- بيانات المناطق والمدن المبدئية مستوردة من بيانات المشروع الحالية، ويمكن تعديل المناطق والمدن من الإعدادات.
- صلاحيات الواجهة ليست بديلاً عن RLS؛ migration تضيف سياسات للكيانات الجديدة وتعيد ضبط سياسات حساسة. راجعها قبل تشغيلها في بيئة الإنتاج.

## التحقق بعد التطبيق

- `npm install` أو `bun install`
- `npm run build`
- `npm test`
- `npm run lint`
- اختبر الدخول بحساب مدير النظام، ثم حساب عرض فقط، ثم حساب محرر.
- اختبر إنشاء/تعديل/حذف/استعادة معلن، واستيراد CSV، والقوائم، والحملات، وسجل التدقيق، وتقييد بيانات الفروع.
- راجع Supabase Security Advisors وRender deploy logs بعد النشر.
